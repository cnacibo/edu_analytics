# 📖 FRONTEND
В этом блоке лежит `react` проект фронтенда приложения. Ниже будет написано краткое описание работы блока и выбранных библиотек.

## Структура блока:
```commandline
├── Dockerfile
├── README.md
├── package-lock.json
├── package.json
├── public/
└── src
    ├── api.js
    ├── components
    │   ├── common/
    │   ├── dashboard/
    │   ├── layout/
    │   └── programs/
    ├── pages/
    │   ├── DashboardPage.jsx
    │   ├── ProgramDetailsPage.jsx
    │   ├── ProgramsPage.jsx
    │   └── styles/
    ├── App.css
    ├── App.js
    ├── index.css
    ├── index.js
    ├── reportWebVitals.js
    └── utils
        └── export/
```

Фронтенд взаимодействует с backend-сервером через REST API. Все запросы централизованно описаны
в `api.js`. Статические файлы (логотипы, манифест) находятся в `public/`.

---
## 🔍 Модули

### 1️⃣ components

> Переиспользуемые UI-блоки, разделённые по логике

- `common/` – универсальные компоненты:
  - Индикатор загрузки (`LoadingSpinner`)
  - Блок с сообщением об ошибке и кнопкой повтора (`Error`)
  - Состояние без данных (`EmptyResult`)
  - Пагинация (`Pagination`)

- `dashboard/` – компоненты для дашборда:
  - Столбчатая и круговая диаграммы (`BarChartDashboard`, `PieChartDashboard`)
  - Карта (`MapDashboard`)
  - Список самых дорогих программ (`SortedProgramsList`)
  - Карточки статистики (`StatisticsCard`)

- `layout/` – элементы общей структуры страницы:
  - Шапка (Header)
  - Боковое меню (Sidebar)
  - Основной макет (MainLayout)

- `programs/` – компоненты для отображения списка программ, фильтров, карточек программ и курсов.

Все стили вынесены в отдельные `CSS` файлы для каждого компонента внутри папки `styles/`.

---

### 2️⃣ pages

> Полноценные страницы приложения, использующие `components/` и `api.js`

- `ProgramsPage.jsx` – страница со списком всех программ (hse / vuz) с возможностью поиска и фильтрации.
- `ProgramDetailsPage.jsx` – детальная карточка конкретной программы.
- `DashboardPage.jsx` – страница с аналитикой: статистические карточки, графики и карта.

Каждая страница имеет собственный файл стилей в папке `styles/`.

---

### 3️⃣ api.js

> Единая точка взаимодействия с бэкендом

- `hseApi` - работа с бекендом для получения информации по программам и курсам НИУ ВШЭ.
- `vuzopediaApi` - получение информации по программам из Vuzopedia а также аналитики для дашборда.

Оба объекта используют класс `ApiService` для запросов к бекенду.

---

### 4️⃣ utils/export

> Утилиты для выгрузки данных в различных форматах

- `exportToCSV.js` – экспорт списка программ в CSV.
- `exportToJSON.js` – экспорт списка программ в JSON.
- `exportToPDF.js` – генерация PDF‑отчёта со списком программ (через `jspdf` и `jspdf-autotable`).
- `exportToXLSX.js` – экспорт в Excel (библиотека `xlsx`).
- `formatters.js` – вспомогательные функции форматирования дат, имен файлов и т.д.
- `fonts/` – встроенный шрифт Roboto для корректного отображения кириллицы в PDF.

## 📦 Используемые библиотеки

| Библиотека | Назначение | Почему выбран |
|------------|------------|----------------|
| **React 18** | Основной фреймворк | Современный, компонентный подход, большая экосистема |
| **react-router-dom** | Маршрутизация | Обеспечивает SPA-навигацию без перезагрузки страницы |
| **recharts** | Построение графиков | Простая интеграция с React, хорошая документация, гибкая настройка внешнего вида |
| **@pbe/react-yandex-maps** | Интерактивные карты | Бесплатный и удобный API Яндекс.Карт для визуализации географических данных |
| **jspdf + jspdf-autotable** | Генерация PDF | Лёгкая генерация таблиц и текста, поддержка кириллицы (с подключением шрифта) |
| **xlsx** | Экспорт в Excel | Популярная библиотека для работы с форматом XLSX |
| **react-scripts** | Сборка и dev‑сервер | Стандартный инструмент Create React App, не требует настройки Webpack |
| **ESLint + Prettier** | Линтинг и форматирование кода | Обеспечивает единый стиль кода и выявление ошибок на этапе разработки |

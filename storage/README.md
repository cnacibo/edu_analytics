# 📖 STORAGE
В этой директории собраны основные файлы полученные путем веб-скрапинга сайтов и анализа их содержимого

## Структура блока:
```commandline
├── storage/
│   ├── files/
│   │   ├── graphs/
│   │   │   ├── graph_data.json
│   │   ├── hse_courses/
│   │   │   ├── hse_course.csv
│   │   │   ├── hse_course.json
│   │   ├── hse_programs/
│   │   │   ├── hse_programs.csv
│   │   │   ├── hse_programs.json
│   │   ├── vyzopedia_programs/
│   │   │   ├── vuzopedia_bachelor_programs.csv
│   │   │   ├── vuzopedia_bachelor_programs.json
│   │   │   ├── vuzopedia_master_programs.csv
│   │   │   ├── vuzopedia_master_programs.json
│   ├── README.md                                     # этот файл
│   └── file_manager.py
```

## 1️⃣ files

> Папка для хранения файлов, полученных путем анализа (`graphs/`) или путем веб-скрапинга

| Номер | Папка                   | Описание                                                                                                 |
|-------|-------------------------|----------------------------------------------------------------------------------------------------------|
| 1️⃣   | `graphs/ `              | Директория для хранения графа знаний.                                                                    |
| 2️⃣   | `hse_courses/`          | Директория для хранения дисциплин двух программ НИУ ВШЭ: ПИ  и ПМИ                                       |
| 3️⃣   | `hse_programs/`         | Директория для хранения направлений бакалавриата и магистратуры в ФКН НИУ ВШЭ                            |
| 4️⃣   | `vyzopedia_programs/`   | Директория для хранения направлений бакалавриата и магистратуры по всей стране, взятых с сайте Вузопедия |
| 5️⃣   | `program_cities`        | Директория для хранения городов в которых реализуется данная программа                                   |

- `file_manager.py` - маршрутизатор для других модулей (например, для parser`a), обеспечивающий логику сохранения файлов

## Какие данные забираем с сайтов?

### HSE course - дисциплины ПМИ и ПИ в НИУ ВШЭ

Пример заполненных полей для одной дициплины
```json
{
      "program_type": "se",
      "url": "https://www.hse.ru/ba/se/courses/1048849927.html",
      "title": "Agile в корпоративной среде",
      "year": "4-й курс",
      "module": "1-3 модуль",
      "status": "Курс по выбору",
      "language": "RUS",
      "credits": 10,
      "content": "1) Развитие цифровых технологий благодаря гибкости бизнеса и тд",
      "results": "Описать, что необходимо для развития цифровых технологий; и тд"
    }
```
---

### HSE program - список всех программ ФКН НИУ ВШЭ (бакалавриат + магистратура)

Пример заполненных полей для одной программы
```json
{
      "id": 3,
      "name": "Прикладная математика и информатика",
      "code": "01.03.04",
      "cost": 700.0,
      "study_type": "Бакалавр",
      "url": "https://www.hse.ru/ba/ami/",
      "budget_places": 195,
      "paid_places": 220,
      "foreigners_places": 29
    }
```
---

### Program cities - соотнесение программ и городам, где эти программы реализуются

Пример заполненных полей для одной программы (ширина и долгота добавляются для визуализации
в дашборде в вкладке карты)

```json

    "city": "Обнинск",
    "latitude": 55.0951738,
    "longitude": 36.611913
  }
```

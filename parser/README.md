### 2️⃣ scrapers

> Базовыe классы `BaseRunner` и `SeleniumScraper` предоставляет запуск всех скраперов для извлечение текста с сайтов

- `BaseRunner` - выполняет веб-скрапинг с сайта НИУ ВШЭ
- `SeleniumScraper` - выполняет веб-скрапинг с сайта Вузопедии

Модуль работает так что сначала он считывает всю страницу и ищет подходщие теги. В результате чего извлекает необходимые цифру, текст

Рассмотрим пример поиска по html-тегам:

```html
<div class="osnBlockInfo">
                Кем стать после: <span class="lowReg">Государственный служащий, Специалист государственного и муниципального управления, Руководитель <a href="/program/magistratura/13451/prof">и остальные</a></span>.
            </div>
```
Это подблок в блоке ```<div class="col-md-12 col-sm-6 blockNewItem"> </div>``` в котором написана все данные карточки программы

```python

    program = []
    block = soup.find_all("div", class_="blockNewItem")
    low_reg = block.find("span", class_="lowReg")
    if low_reg:
        program["career_prospects"] = low_reg.get_text(strip=True)

```

Псевдо-код показывает, как мы ищем в теге `div` по классу нужное название блока,
затем внутри тега ищем тега `span` аналогично по классу забираем название сферы направления.

### 🔗 Общие сведения

При разработке парсера я столкнулась с двумя типами сайтов:
- статические страницы (например, сайт НИУ ВШЭ)
- динамические, где данные подгружаются через JavaScript (Vuzopedia).


**Почему BeautifulSoup + requests?**

Для сайта НИУ ВШЭ достаточно получить HTML-код страницы через requests.get(),
потому что все данные уже встроены в первоначальный ответ сервера.
`BeautifulSoup` легко извлекает их через CSS-селекторы. Это обеспечивает **высокую сткорость парсинга**


```python
response = requests.get(url)
soup = BeautifulSoup(response.text, 'html.parser')
programs = soup.find_all('div', class_='program-card')
```

**Почему пришлось добавить Selenium?**

Vuzopedia использует динамическую подгрузку карточек программ и всплывающие подсказки (`tooltips`),
которые появляются только при наведении мыши, соотвественно необходимо эмулировать работу браузера.
Однако, такая реализация требует медленне и использует дополнительную память под работу в браузере

**Альтернативы**

| Альтернатива      | Почему нет                                                                                                                                                                                               |
|-------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Scrapy            | Не умеет сам рендерить JS, из-за этого требует подлкючения дополниьельных библиотек, что усложняет работу курсового проекта                                                                              |
| Requests-HTML     | Хорошая библиотека, но при реализации сталкиваешься с постоянными ошибками, недоработками при длительной работе парсинга                                                                                 |
| Прокси + requests | Сайт не дает в таком случаи обойти блокировки и капчу, что является минусом при длительном парсинге и переходам по 100+ страниц внутри сайта, также нужна будет дополнительное подключение рендеринга JS |

## 🔍 Модули

### 1️⃣ analysis – Аналитика

> `Class AnalysisService` предоставляет методы, данные которых отображаются на дашборде сайта.

| Метод | Описание |
|-------|----------|
| `get_max_budget_score()` | Возвращает максимальный балл для поступления на бюджет |
| `get_min_paid_score()` | Возвращает минимальный балл для поступления на платное отделение |
| `get_average_cost()` | Вычисляет среднюю стоимость обучения |
| `get_all_programs()` | Возвращает общее количество программ в Вузопедии |
| `get_top_ten_programs()` | Возвращает топ‑10 программ, отсортированных по стоимости обучения (по убыванию) |
| `get_avg_cost_top10()` | Вычисляет среднюю стоимость обучения среди топ‑10 программ |
| `get_pie_chart()` | Строит круговую диаграмму распределения по сферам (5 самых популярных сфер) |

### 3️⃣ knowledge_graphs – Графы знаний

> Построение графов знаний – визуализация связей между направлениями, дисциплинами и тегами.

#### 🖥 Локальный запуск

Чтобы посмотреть общий вид графа с тегами, выполните инструкцию:

1. Перейдите в папку с модулем:
   ```bash
   cd ml/knowledge_graphs/

2. Откройте файл `main.py` и раскомментируйте строки `fig = create_figure(G, pos, threshold=0.8)` и `fig.show()`.

    > По желанию можно закомментировать строку сохранения результата в файл – для отображения графа она не нужна:
`export_to_json(G, pos, export_path)`

3. Запустите скрипт:

    ```bash
    python3 main.py
    ```

#### 🔗 Как строятся связи (Plotly.js)

- Серые рёбра соединяют «Название программы» → «Название предмета» этой программы.
- Красные рёбра соединяют исключительно теги между собой.

  Толщина красного ребра зависит от косинусовой близости между тегами.

**Почему рёбра разной толщины?**

Каждый тег представлен в виде вектора (эмбеддинга).
Косинусовая близость – это угол между векторами, нормализованный в диапазон от –1 до 1:

- 1 – векторы сонаправлены (очень близки по смыслу)
- 0 – векторы ортогональны (не связаны)
- –1 – векторы противоположны (редко)

Я задаю порог (например, 0.8). Все пары тегов, чья близость превышает порог, считаются связанными.
Чем ближе значение к 1, тем толще ребро; чем дальше от порога, тем тоньше.

**Откуда берутся вектора?**

Векторы – это эмбеддинги тегов, полученные с помощью модели Rubert‑tiny2.
Координаты сохраняются в JSON-файле, который используется для визуализации.





```json
"nodes": [
    {
      "label": "Программная инженерия",    ->  название программы
      "type": "direction",                 ->  тип программы
      "x": -0.11650671579306983,           ->  координаты программы
      "y": -0.1467368730166153
    },
]
```
```json
"edges": [
    {
      "source": "Программная инженерия",        ->  название дисциплины
      "target": "Agile в корпоративной среде",  ->  название связи
      "type": "explicit",                       ->  тип связи
      "weight": 1.0                             ->  ширина ребра
    },
```
